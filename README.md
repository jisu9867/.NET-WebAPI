# WebApplication1

Simple ASP.NET Core web application (template). Run locally with dotnet.

Run:

```powershell
cd 'C:\Users\wltn9\Desktop\code\tmp\WebApplication1'
dotnet run
```

Open in browser:

```powershell
Start-Process 'https://localhost:7272'
# or
Start-Process 'http://localhost:5028'
```
